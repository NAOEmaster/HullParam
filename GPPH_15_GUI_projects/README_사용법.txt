GPPH GUI 비교용: 선저 종거더(Girder) 간격·높이, 늑골 간격

총 15개 프로젝트: G00~G04 종거더 간격 5종 / H00~H04 종거더 높이 5종 /
F00~F04 늑골 간격 5종. 각 그룹의 00_original은 원본 파라미터 그대로입니다.
비교 변수 이외의 선체 외판, 판 두께, 부재 개수, 종보강재 단면은 유지했습니다.

GUI에서 열기: 기존 HullParam 프로그램의 run.bat 실행 → 프로젝트 열기에서
각 프로젝트 폴더를 선택 → 검증 → ▶ 생성 → 같은 시점·표시 조건으로 캡처.
기존 out 폴더는 생성 결과 기록이며 GUI가 자동 표시하지 않으므로, 폴더를
바꿀 때마다 ▶ 생성을 다시 눌러야 합니다. 상세 결과는 각 out의 BREP,
속성 CSV, 검사 JSON 및 상위 cases.csv에서 볼 수 있습니다.

G: Girder1 |y|=403.5 mm 고정, Girder2의 |y|만 변경 (좌우 대칭).
   기준 Girder2 |y| 1210.5 mm, G01~G04 925 / 1125 / 1325 / 1525 mm.
   같은 쪽 두 거더 사이 간격: 기준 807.0 mm,
   변경 521.5 / 721.5 / 921.5 / 1121.5 mm.
   두 거더는 수직 쉘이며, 위치 변경 때 외판과의 교차 형상도 갱신됩니다.

H: Girder1의 길이방향 상단 높이 z_top(x)를 원래의 경사와 형상을 유지하며
   각각 +30 / +60 / +90 / +120 mm 평행 이동.
   기준 선미 z_top=588.0 mm, 후방 램프 이후 z_top=507.5 mm.
   H01은 618.0→537.5 mm, H02는 648.0→567.5 mm,
   H03은 678.0→597.5 mm, H04는 708.0→627.5 mm입니다.
   같은 선체 위치에서 거더 쉘의 높이와 면적이 실제로 바뀝니다.

F: 선미측 늑골 F1~F4의 x 좌표만 변경, 격벽 2개 및 나머지 늑골 유지.
   기준: 1327.6 / 2655.2 / 3982.8 / 5310.3 mm.
   F01: 1100 / 2200 / 3300 / 4400 mm.
   F02: 1200 / 2400 / 3600 / 4800 mm.
   F03: 1400 / 2800 / 4200 / 5600 mm.
   F04: 1500 / 3000 / 4500 / 6000 mm.

원본부터 트랜섬 보강재 2개가 외판 밖에 있어 검사가 WARN으로 표시됩니다.
각 변경 모델은 틈, 떠 있는 빔, 무효 형상 0개를 확인했습니다.
